Memahami Multiplexer dan Demultiplexer

Jelajahi konsep dasar, prinsip kerja, dan aplikasi dari dua komponen penting dalam sistem komunikasi digital ini. Pelajari bagaimana data dapat digabungkan dan dipisahkan secara efisien.

Apa itu Multiplexer (MUX)?

Multiplexer (MUX) adalah sebuah rangkaian logika kombinasional yang memilih satu dari beberapa input dan meneruskan data dari input tersebut ke satu saluran output tunggal. Seleksi input mana yang akan diteruskan ditentukan oleh kendali seleksi.

Multiplexer sering disebut sebagai "data selector" karena fungsinya yang memilih satu dari banyak input. Komponen ini sangat penting dalam sistem digital untuk mengurangi jumlah kabel atau saluran yang diperlukan untuk mentransmisikan data.

Cara Kerja Multiplexer:

  1. Memiliki beberapa saluran input (biasanya 2, 4, 8, 16, atau 32)
  2. Memiliki satu saluran output
  3. Memiliki saluran kendali seleksi yang menentukan input mana yang akan diteruskan ke output
  4. Data dari input yang dipilih akan diteruskan ke output

Diagram Multiplexer 4:1

Multiplexer 4:1 memiliki 4 input, 1 output, dan 2 jalur kendali seleksi (karena 2² = 4)

Rumus Logika Multiplexer:

Output = (I₀·S₁'·S₀') + (I₁·S₁'·S₀) + (I₂·S₁·S₀') + (I₃·S₁·S₀)

Dimana I₀-I₃ adalah input, S₀ dan S₁ adalah kendali seleksi.

Apa itu Demultiplexer (DEMUX)?

Demultiplexer (DEMUX) adalah kebalikan dari multiplexer. Komponen ini menerima satu input dan mendistribusikannya ke salah satu dari beberapa output. Output mana yang akan menerima data ditentukan oleh kendali seleksi.

Demultiplexer sering disebut sebagai "data distributor" karena fungsinya yang mendistribusikan satu input ke banyak output. Komponen ini berguna ketika kita perlu mengirim data dari satu sumber ke banyak tujuan.

Cara Kerja Demultiplexer:

  1. Memiliki satu saluran input
  2. Memiliki beberapa saluran output (biasanya 2, 4, 8, 16, atau 32)
  3. Memiliki saluran kendali seleksi yang menentukan output mana yang akan menerima data
  4. Data dari input akan diteruskan ke output yang dipilih

Diagram Demultiplexer 1:4

Demultiplexer 1:4 memiliki 1 input, 4 output, dan 2 jalur kendali seleksi (karena 2² = 4)

Rumus Logika Demultiplexer:

Output₀ = Input·S₁'·S₀'

Output₁ = Input·S₁'·S₀

Output₂ = Input·S₁·S₀'

Output₃ = Input·S₁·S₀

Dimana Input adalah data masukan, S₀ dan S₁ adalah kendali seleksi.

Perbedaan Multiplexer dan Demultiplexer

Meskipun keduanya adalah komponen penting dalam sistem komunikasi digital, multiplexer dan demultiplexer memiliki fungsi yang berlawanan. Berikut perbedaan utama antara keduanya:

Kesimpulan:

Multiplexer dan Demultiplexer adalah dua komplementer yang sering digunakan bersama dalam sistem komunikasi. Multiplexer menggabungkan beberapa sinyal menjadi satu untuk transmisi, sementara Demultiplexer memisahkannya kembali di sisi penerima.

Fakta Menarik

  • Multiplexer dan Demultiplexer adalah komponen dasar dalam desain CPU
  • Teknologi multiplexing digunakan dalam komunikasi satelit
  • Jaringan Wi-Fi menggunakan multiplexing untuk mengirim data ke banyak perangkat
  • TV kabel menggunakan multiplexing untuk mengirim banyak channel melalui satu kabel
  • Smartphone menggunakan multiplexing untuk berbagai fungsi komunikasi
